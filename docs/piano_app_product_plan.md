# 免费钢琴练习 App 产品规划

## 1. 产品定位

目标不是简单复制虫虫钢琴，而是做一个更轻、更免费、更容易上手的钢琴练习工具。

一句话定位：

> 免费钢琴曲谱与智能练习 App，让零基础和初中级用户能快速找谱、看谱、听谱、跟练。

第一阶段重点用户：

- 成人零基础自学用户
- 有孩子学琴、想辅助练琴的家长
- 会一点钢琴、经常找流行歌和经典曲练习的用户

第一阶段不建议主攻：

- 专业考级机构
- 高阶钢琴演奏者
- 重社区内容平台
- 复杂 AI 陪练全自动评分

原因：这些方向成本高、版权要求高、技术难度高，早期容易拖慢上线。

## 2. 对标拆解

虫虫钢琴的公开核心能力可以拆成 5 类：

- 曲谱内容：海量曲谱、分类、搜索、收藏、下载、打印
- 智能曲谱：AI 播放、五线谱转简谱、指法标注、变速、变调
- 练习工具：瀑布流、虚拟钢琴键盘、左右手分练、选段循环
- 陪练纠错：麦克风识别、错音标记、测评打分
- 课程与社区：成人课程、真人示范、用户交流和投稿

我们的切入点：

- 先做“找谱 + 练谱”体验
- 再做“智能纠错”
- 最后做“课程/社区/会员”

## 3. MVP 版本

MVP 目标：用户打开 App 后，能搜索一首曲子，打开曲谱，播放示范，跟着练习，并保存练习记录。

### 3.1 首页

功能：

- 推荐曲谱
- 热门分类：流行、古典、入门、儿童、考级、动漫
- 搜索入口
- 最近练习

目标：

- 让用户不用理解复杂功能，直接开始找曲子。

### 3.2 曲谱库

功能：

- 曲谱列表
- 关键词搜索
- 难度筛选
- 曲风分类
- 收藏

曲谱元数据：

- 曲名
- 作者/编配者
- 难度
- 曲风
- 是否有 MIDI
- 是否支持跟练
- 是否公版/授权/用户上传

### 3.3 曲谱详情页

功能：

- MusicXML 谱面预览
- 播放示范
- 开始练习
- 收藏
- PDF/图片原谱下载或打印入口（仅作为补充）
- 曲谱来源说明

### 3.4 曲谱阅读器

MVP 必做：

- MusicXML 谱面展示
- 放大缩小
- 翻页
- 横屏模式
- OSMD 光标跟弹高亮
- MIDI 播放同步

后续增强：

- 小节定位
- 当前播放位置高亮
- PDF/图片原谱查看、下载、打印
- 五线谱/简谱切换

### 3.5 练习模式

MVP 必做：

- MIDI 播放
- 速度调节：0.5x、0.75x、1x、1.25x
- A-B 片段循环
- 左手/右手分轨播放
- 底部虚拟钢琴键盘高亮

暂不做：

- 复杂实时纠错
- AI 自动生成指法
- 自动五线谱转简谱

原因：MVP 先验证用户是否愿意用免费曲谱和练习工具留下来。

### 3.6 我的页面

功能：

- 收藏曲谱
- 练习历史
- 每日练习时长
- 连续练习天数
- 设置

## 4. 版本路线

### V0.1 原型验证

目标：做出可点击原型，确认页面结构和用户流程。

范围：

- 首页
- 曲谱库
- 曲谱详情
- 曲谱阅读器
- 练习模式
- 我的页面

交付：

- Web/PWA 原型
- 可在手机浏览器打开
- 使用模拟曲谱数据

### V0.2 技术 MVP

目标：做出能真实使用的最小版本。

范围：

- 用户注册/登录
- 曲谱数据后台
- MusicXML 曲谱上传与展示
- MIDI 播放
- 搜索和收藏
- 练习记录

建议先做 Web/PWA，再封装 App。

### V0.3 内容 MVP

目标：建立第一批可合法使用的曲谱内容。

范围：

- 公版曲谱导入
- 用户上传
- 后台审核
- 曲谱版权标记
- 基础推荐位

关键点：

- 不抓取付费谱
- 不复制竞品内容
- 每个曲谱有来源和版权状态

### V0.4 练习增强

目标：让练琴体验明显区别于普通 PDF 曲谱站。

范围：

- MIDI 与曲谱页同步
- 小节循环
- 练习目标
- 分手练习
- 每日练习计划
- 简单打卡体系

### V1.0 上线版本

目标：可公开发布、可增长、可商业化测试。

范围：

- App 封装
- 首页推荐
- 曲谱搜索
- 智能练习
- 收藏和历史
- 广告位
- 基础会员体系
- 内容审核后台

## 5. 技术路线

### 推荐架构

第一阶段建议用：

- 前端：React + Vite + PWA
- 移动端封装：Capacitor
- 后端：Node.js / NestJS 或 Supabase
- 数据库：PostgreSQL
- 文件存储：S3 兼容对象存储
- 音频/MIDI：Tone.js 或 Web MIDI 相关库
- 跟弹谱面渲染：OpenSheetMusicDisplay（OSMD）+ MusicXML
- PDF/图片：只用于看原谱、下载、打印，不承载跟弹高亮

选择理由：

- 先做 Web/PWA 成本最低
- 后续可以封装成 iOS/Android
- MusicXML 谱面渲染、MIDI 播放、收藏、搜索都适合 Web 技术
- 早期不用立刻承担原生 App 的复杂开发成本

### 后续再考虑原生能力

如果要做实时陪练纠错，后续可能需要：

- 麦克风音高识别
- 音频降噪
- 低延迟音频处理
- 原生 iOS/Android 音频模块

这不应该放进第一版。

## 6. 内容与版权策略

这是项目成败的关键。

不能做：

- 爬取虫虫钢琴付费曲谱
- 绕过会员下载
- 未授权搬运流行歌曲曲谱
- 用户上传后不审核直接公开传播

可以做：

- 公版古典曲谱
- 用户原创曲谱
- 用户自己上传仅个人使用
- 与编配者合作分成
- AI/MIDI 生成练习版本，但需要标注来源和版权状态

早期内容策略：

- 先准备 100-300 首公版和入门曲
- 覆盖小星星、欢乐颂、卡农片段、土耳其进行曲等入门/古典曲
- 每首优先配 MusicXML + MIDI/音符序列，确保能做“弹到哪亮到哪”
- PDF/图片只作为看原谱、下载、打印的附属格式，不能作为跟弹主格式
- 用“免费、好练、跟弹清楚”做差异化

## 7. 商业化规划

第一阶段不要急着收费，先验证留存。

### 免费能力

- 基础曲谱浏览
- 收藏
- MIDI 播放
- 基础练习模式
- 每天有限次数下载

### 广告

适合位置：

- 曲谱详情页底部
- 搜索结果页信息流
- 下载前激励广告

不建议：

- 练琴中频繁弹窗
- 曲谱阅读器中遮挡广告
- 播放过程中打断广告

### 会员

可收费能力：

- 无广告
- 无限下载/打印
- 高级练习模式
- 云端同步
- 高级曲谱包
- AI 纠错和练习报告
- 离线曲谱

### 内容分成

后期可以让编配者上传曲谱：

- 免费谱获得曝光
- 付费谱分成
- 平台抽佣

## 8. 核心指标

早期只看这些：

- 新用户次日留存
- 每人收藏曲谱数
- 每人练习曲谱数
- 单次练习时长
- 搜索无结果率
- 曲谱打开到开始练习转化率
- 曲谱播放/跟练完成率

不建议早期过度关注：

- 会员收入
- 社区发帖数
- 大而全功能数量

## 9. 最大风险

### 风险 1：版权

解决方式：

- 建立曲谱版权字段
- 上传审核
- 优先做公版和原创
- 不从竞品搬内容

### 风险 2：内容不足

解决方式：

- 先聚焦入门和热门公版曲
- 每首曲尽量提供 MusicXML + MIDI/音符序列
- 做用户上传和投稿激励

### 风险 3：技术过早复杂化

解决方式：

- 第一版不做实时 AI 纠错
- 先做 MIDI 跟练和练习记录
- 验证留存后再投入音频识别

### 风险 4：免费但不赚钱

解决方式：

- 免费基础体验必须完整
- 广告只放在不打断练习的位置
- 会员卖高级效率，而不是锁死基础功能

## 10. 下一步执行建议

建议下一步直接做 V0.1 可点击原型。

页面顺序：

1. 首页
2. 曲谱库
3. 曲谱详情
4. 曲谱阅读器
5. 练习模式
6. 我的页面

原型目标：

- 先把产品体验跑通
- 不接真实后台
- 用 10-20 首模拟曲谱
- 做出接近真实 App 的手机界面

确认原型后，再进入技术 MVP。
